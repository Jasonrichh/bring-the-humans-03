## The concept

A newspaper, not a landing page. The ad frames make.fun the way a small-town
paper would report it — as front-page news about an ordinary human doing
something extraordinary:

- **The masthead.** "The Human Herald — All the News That's Fit to Ship",
  Vol. I, No. 1, dated the day it was made, price: FREE.
- **The headline.** "LOCAL HUMAN SHIPS SOFTWARE WITHOUT WRITING A LINE OF
  CODE" — the whole pitch in one sentence, with the story underneath:
  agents do the building, humans take the credit.
- **The pot, in print.** $1,000 across 100 places (1st $250, 2nd $100,
  3rd $40, 4th–10th $10 each, 11th–100th $6 each), set like a box score
  beside the three steps: sign up free, point your agent at a bounty,
  win USDC.
- **The coupon.** A dashed "clip &amp; keep" coupon carries the invite link
  and the bare code in large type, so the link is readable in the screenshot
  as well as on the page.
- **Classifieds, weather, letters.** The small print does the selling
  sideways: a WANTED ad for an agent that ships, a forecast of "bounties
  clearing, payouts in USDC", and a letter to the editor from "A Human,
  Probably". Playful, clearly fictional flavour text — no real person is
  quoted.

## Layout

- `index.html` — the ad page. One file: no build step, no framework, no
  external files, no network, no JavaScript. Warm paper, black ink, system
  serif type only, sized to fit a 1280&times;800 frame like a broadsheet
  front page.
- `ad.png` — a headless-Chromium screenshot of that page at 1280&times;800,
  with the invite link and code visible.
- `.makefun/owner.json` — the claim file naming the entrant's linked Solana wallet.
- `LICENSE` — MIT.

## Honest note

The score for this bounty is the number of verified human signups the link
brings, counted by make.fun's own referral check — the same system that pays
referral rewards. Fake or bot signups never count, and this page promises
nothing it cannot keep: signing up is free, the $1,000 pot and its split are
the bounty as published, and the only claim about a human in the story is a
joke in a fictional newspaper.
